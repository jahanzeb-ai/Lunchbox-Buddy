# 🥪 Lunchbox Buddy

**Eat • Play • Explore!**

Lunchbox Buddy is a creative AI tool concept designed to make children's lunchtime more engaging through personalized stories, missions and positive rewards.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Creative AI concept

The current prototype demonstrates the user experience. A generative AI API can be connected so that Lunchbox Buddy creates a new personalized mission, story, character dialogue and encouragement from the child's name and lunchbox foods.

## Future AI features

- Personalized AI lunch stories
- AI-generated characters
- Voice narration
- Child-friendly encouragement
- Parent dashboard
- Daily variety of missions

This is a prototype, not a medical or nutritional assessment tool.
